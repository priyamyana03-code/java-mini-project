About ARTIST HUB

A Java-Based Artist Learning & Teaching Platform designed to bridge the gap between creative mentors and aspiring students.

Problem Statement & Vision

Empowering Aspiring Artists & Teachers

Traditional art education is often fragmented. Students struggle to find trustworthy mentors, clear fee structures, transparent course schedules, or accessible beginner workshops. At the same time, talented independent artists lack a dedicated platform to showcase their expertise and teach students.

Artist Hub solves this by offering a clean, unified portal where students can discover teachers, explore online and offline classes across 4 key art categories (Painting, Sketching, Pastel, and Doodling), enroll in classes (including a free beginner session), and read authentic peer reviews.

Simple Architecture
Layered Spring Boot REST API for easy viva explanation.
Real-Time Data
Dynamic seat tracking, JPA relationships & MySQL persistence.

Core Objectives

  • Teacher Discovery Browse verified artist mentors with bios, qualifications, and student ratings.
  • Class Catalog & Filtering Filter by discipline (Painting, Sketching, Pastel, Doodling), mode (Online/Offline), and level.
  • Free Beginner Class Encourage art adoption with a completely free ₹0 Beginner Doodling Class.
  • Enrollment & Capacity Control Prevent overbooking by validating maximum students and tracking available seats.
  • Community Ratings & Reviews Allow students to publish star ratings and constructive feedback.
Our Creative Philosophy

Learn. Create. Share.

Artist Hub is built on three guiding principles designed to unlock creativity in everyone, regardless of prior experience.

Learn

Access structured, 4-lesson curriculum pathways created by recognized fine art scholars. From fundamental strokes to advanced techniques, master disciplines at your own pace.

Create

Put theory into practice with guided hands-on canvas projects, sketchbook challenges, and tactile pastel landscapes that build real confidence with real tools.

Share

Connect with fellow art enthusiasts, ask direct questions to instructors in our Q&A forum, and celebrate artistic milestones in a welcoming, encouraging community.

The frontend uses modern asynchronous JavaScript fetch() API to make HTTP requests (GET, POST) to Spring Boot @RestController endpoints (e.g., /api/classes, /api/enrollments). Data is exchanged using standard JSON.

With the property spring.jpa.hibernate.ddl-auto=update, Hibernate inspects all entity classes (@Entity like Teacher, ArtClass, Enrollment) and automatically maps Java fields into corresponding database columns, tables, and foreign keys when the application boots.

Inside EnrollmentService.java, before creating an enrollment record, the service checks enrolledStudents >= maxStudents. If full, it throws an IllegalStateException, and the controller returns an HTTP 400 Bad Request with an informative error message.

The DataInitializer component implements Spring Boot's CommandLineRunner. At startup, it checks if (teacherRepository.count() == 0) before inserting sample mentors, classes, and reviews, ensuring existing data is never duplicated on restarts.
